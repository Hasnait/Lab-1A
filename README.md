## Project Description

This repository contains the work completed for Lab 1 of the Embedded Development course.

The project uses an ESP32 microcontroller programmed with the Arduino framework through PlatformIO in Visual Studio Code.

## Lab 1A – GPIO

The objective is to understand GPIO (General Purpose Input/Output) using an ESP32.

The practical assignment involves:
- Controlling an LED using a GPIO output.
- Reading button presses through a GPIO input.
- Toggling the LED state whenever the button is pressed.
- Implementing button debouncing.

## Lab 1B – Git and GitHub

This part focuses on learning version control and collaboration using Git and GitHub.

The activities include:
- Creating and managing a GitHub repository.
- Tracking changes using Git.
- Creating branches and commits.
- Creating and reviewing Pull Requests.
- Collaborating with another student.
